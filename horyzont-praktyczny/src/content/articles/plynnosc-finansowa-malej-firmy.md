W rachunku zysków i strat sprzedaż pojawia się w momencie wystawienia faktury. Na koncie – dopiero gdy klient zapłaci. W międzyczasie trzeba zapłacić dostawcom, pracownikom, ZUS i urzędowi skarbowemu. Ta luka czasowa to główne źródło problemów z płynnością w małych firmach.

## Zysk a przepływ gotówki – trzy typowe pułapki

1. **Szybki wzrost sprzedaży** – większe zamówienia oznaczają wyższe zakupy materiałów i zapasów, a zapłata od klientów przychodzi po terminie płatności.
2. **Długie terminy płatności klientów** przy krótkich terminach u dostawców.
3. **Wydatki nieregularne** – podatek roczny, ubezpieczenia, sezonowe zakupy – które nie pojawiają się w miesięcznych zestawieniach.

## Prognoza przepływów na 13 tygodni

Prosty arkusz wystarczy, by zobaczyć zbliżający się problem z kilkutygodniowym wyprzedzeniem. Struktura:

| Pozycja | Tydzień 1 | Tydzień 2 | … | Tydzień 13 |
|---|---|---|---|---|
| Saldo początkowe | | | | |
| Wpływy od klientów (wg terminów faktur) | | | | |
| Inne wpływy | | | | |
| Wynagrodzenia | | | | |
| Dostawcy | | | | |
| Podatki i składki | | | | |
| Raty, leasing, czynsz | | | | |
| Saldo końcowe | | | | |

Raz w tygodniu aktualizuj dane: wpisz faktyczne wpływy, przesuń nieopłacone faktury, dodaj nowe zobowiązania. Kluczowy wskaźnik to **najniższe saldo w horyzoncie prognozy** – jeśli spada poniżej bezpiecznego poziomu, masz czas, by zareagować.

## Cykl konwersji gotówki

To liczba dni od zapłaty dostawcy do otrzymania pieniędzy od klienta. Składa się z:

- czasu rotacji zapasów (ile dni towar leży w magazynie),
- czasu spływu należności (ile dni czekasz na zapłatę),
- minus czas spłaty zobowiązań (ile dni masz na zapłatę dostawcom).

Im krótszy cykl, tym mniej gotówki „zamrożonej” w działalności. Każdy z elementów można poprawiać osobno.

## Terminy płatności i przepisy

W transakcjach między przedsiębiorcami przepisy ograniczają długość terminów zapłaty – co do zasady do 60 dni. Dłuższy termin jest możliwy, gdy strony wyraźnie go uzgodnią i nie jest rażąco nieuczciwy wobec wierzyciela – z wyjątkiem transakcji, w których dłużnikiem jest duży przedsiębiorca, a wierzycielem mikro, mały lub średni przedsiębiorca, oraz transakcji z podmiotami publicznymi, dla których obowiązują sztywne limity. Przy opóźnieniu wierzycielowi przysługują odsetki ustawowe za opóźnienie w transakcjach handlowych oraz rekompensata za koszty odzyskiwania należności w kwocie zależnej od wartości świadczenia.

Pomocna bywa też tzw. ulga na złe długi, pozwalająca w określonych warunkach skorygować podatek z niezapłaconych faktur.

## Narzędzia ochrony płynności

- **Zaliczki i przedpłaty** – szczególnie przy dużych zleceniach i produkcji na zamówienie.
- **Płatności etapowe** w długich projektach.
- **Szybka windykacja** – przypomnienie przed terminem, telefon w dniu po terminie, wezwanie do zapłaty po kilku dniach.
- **Faktoring** – sprzedaż należności firmie faktoringowej w zamian za szybszą wypłatę środków (za prowizję).
- **Limit w rachunku lub kredyt obrotowy** – jako bufor, a nie stałe źródło finansowania.
- **Rezerwa gotówkowa** – np. równowartość kilku tygodni kosztów stałych.

> **Weryfikuj klientów:** przed dużym zamówieniem z odroczoną płatnością sprawdź kontrahenta w publicznych rejestrach i bazach informacji gospodarczej. Ustal limit kredytu kupieckiego dla każdego klienta.

## Sygnały ostrzegawcze

1. Regularne opóźnienia w płatnościach podatków lub składek.
2. Rosnący udział przeterminowanych należności.
3. Finansowanie bieżących wydatków limitem w koncie przez wiele miesięcy.
4. Brak wiedzy, ile gotówki firma będzie mieć za miesiąc.

## Podsumowanie

Płynność to zdolność do terminowego płacenia zobowiązań – i da się nią zarządzać. Tygodniowa prognoza przepływów, świadoma polityka terminów płatności, konsekwentna windykacja i rezerwa gotówkowa ograniczają ryzyko, że rentowna firma utknie z powodu braku pieniędzy na koncie.
